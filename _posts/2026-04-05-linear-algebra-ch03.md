## 1. 변환(Transformation) = 함수(Function)

'변환'은 함수의 다른 표현이다. 입력을 받아 출력을 내보낸다.  
선형대수에서는 **벡터 → 벡터**로 이동시키는 변환을 다룬다.

> 굳이 '변환'이라 부르는 이유: **입력-출력을 공간의 이동으로 시각화**하기 위해서

### 시각화 방법

```
각 벡터를 화살표가 아닌 → 끝점(점)으로 생각하기
그러면 공간의 모든 점이 다른 점으로 이동하는 장면을 관찰 가능
```

- 무한한 격자(grid) 전체를 함께 이동시키면 변환의 전체 형태가 보인다
- 원래 격자를 배경으로 유지하면 출발점 대비 도착점을 비교할 수 있다
- 공간 자체가 압축되고 변형되는 것처럼 보인다

## 2. 선형 변환 (Linear Transformation) 의 조건

모든 변환이 선형은 아니다. 선형대수는 **선형 변환만** 다룬다.

### 두 가지 조건

| 조건 | 설명 |
| --- | --- |
| **직선 유지** | 변환 후에도 모든 직선이 곡선 없이 직선으로 남아야 함 |
| **원점 고정** | 원점(0, 0)은 변환 후에도 그 자리에 있어야 함 |

### 시각적 특징으로 표현하면

> 선형 변환 = **격자선이 평행하고 등간격으로 유지**되는 변환

- 격자선이 구부러지면 → 선형 변환 ❌
- 원점이 이동하면 → 선형 변환 ❌

## 3. 기저 벡터 2개로 변환 전체를 기술한다

선형 변환의 핵심 성질:

> **î(i-hat)과 ĵ(j-hat)이 각각 어디로 이동하는지만 알면, 공간의 모든 벡터의 변환을 알 수 있다**

### 왜 그럴까? — 선형 조합이 보존된다

벡터 `v = (-1, 2)`는 기저 벡터로 이렇게 표현된다:

```
v = -1 × î  +  2 × ĵ
```

변환 T를 적용하면:

```
T(v) = -1 × T(î)  +  2 × T(ĵ)
```

변환 전에 î, ĵ의 선형 조합이었다면 → **변환 후에도 T(î), T(ĵ)의 동일한 선형 조합**

### 구체적인 예시

î → (1, -2), ĵ → (3, 0) 으로 이동하는 변환에서 v = (-1, 2)의 도착점:

```
T(v) = (-1) × (1, -2)  +  (2) × (3, 0)
     = (-1, 2)  +  (6, 0)
     = (5, 2)
```

### 일반화

일반 벡터 `(x, y)`의 변환 결과:

```
T(x, y) = x × T(î)  +  y × T(ĵ)
```

→ **2D 선형 변환은 단 4개의 숫자(î 도착 좌표 2개 + ĵ 도착 좌표 2개)로 완전히 기술된다**

## 4. 행렬 (Matrix) — 변환을 패키징한 것

이 4개의 숫자를 **2×2 행렬**로 묶는다.

```
     [ a  b ]
M =  [      ]      ←  1열(a,c) = î 도착점, 2열(b,d) = ĵ 도착점
     [ c  d ]
```

> **행렬의 열(column) = 기저 벡터가 도달하는 좌표**

### 행렬-벡터 곱셈 = 변환 적용

```
[ a  b ] [ x ]         [ a ]       [ b ]   [ ax + by ]
[      ] [   ] = x  ×  [   ]  + y ×[   ] = [         ]
[ c  d ] [ y ]         [ c ]       [ d ]   [ cx + dy ]
```

- 암기가 아니라, **새로운 기저 벡터들의 스케일된 선형 조합**이라는 개념에서 나온 결과

## 5. 대표적인 선형 변환과 행렬

| 변환 | î 도착점 | ĵ 도착점 | 행렬 |
| --- | --- | --- | --- |
| 항등 (변환 없음) | (1, 0) | (0, 1) | `[[1,0],[0,1]]` |
| 90° 반시계 회전 | (0, 1) | (-1, 0) | `[[0,-1],[1,0]]` |
| 전단 (Shear) | (1, 0) | (1, 1) | `[[1,1],[0,1]]` |
| x축 대칭 | (1, 0) | (0, -1) | `[[1,0],[0,-1]]` |

### 예시: 90° 반시계 회전

벡터 (3, 2)를 90° 반시계 방향으로 회전:

```
[ 0  -1 ] [ 3 ]         [ 0 ]        [ -1 ]   [ -2 ]
[       ] [   ] = 3  ×  [  ]  + 2 ×  [   ] =  [    ]
[ 1   0 ] [ 2 ]         [ 1 ]        [  0 ]   [  3 ]
```

→ (3, 2) **→** (-2, 3)

### 예시: 전단 (Shear) 변환

전단 변환에서 i-hat은 고정, j-hat이 (1, 1)로 이동:

```
[ 1  1 ] [ x ]   [ x + y ]
[      ] [   ] = [       ]
[ 0  1 ] [ y ]   [   y   ]
```

→ x 좌표만 y값만큼 밀려나고, y 좌표는 그대로

## 6. 열 벡터가 선형 종속이면? — 차원 압축

행렬의 두 열이 **선형 종속**(하나가 다른 하나의 스칼라 배)이면:

```
예: î → (2, 1), ĵ → (4, 2)  →  ĵ = 2 × î  →  선형 종속
```

- 2D 공간 전체가 **1D 직선으로 납작하게 압축**된다
- 이것이 **행렬식(determinant) = 0**이 되는 상황 (다음 챕터에서 자세히)

## 핵심 정리 한눈에

```
변환(Transformation)  →  벡터를 다른 벡터로 이동시키는 함수
선형 변환              →  직선 유지 + 원점 고정 (= 격자 평행·등간격 유지)
기저 벡터 î, ĵ        →  도착점 4개 숫자로 변환 전체 기술 가능
행렬 (2×2)            →  열 = 기저 벡터 도착점 (변환의 패키지)
행렬-벡터 곱          →  x·(1열) + y·(2열) = 변환 적용
열이 선형 종속         →  차원 압축 발생, determinant = 0
```
