## 1. 개요 — 왜 고유벡터/고유값인가?

고유벡터(Eigenvector)와 고유값(Eigenvalue)은 선형대수학에서 **"변환의 본질을 꿰뚫는 렌즈"** 역할을 한다.

대부분의 교과서는 행렬식 계산과 특성방정식 풀이에 집중하지만, 3Blue1Brown은 **기하학적 직관**을 먼저 강조한다:

> "선형 변환을 가했을 때, 방향이 바뀌지 않는 특별한 벡터가 있다."

이 개념을 이해하려면 아래 개념들이 선행되어야 한다.

| 선행 개념 | 핵심 내용 |
| --- | --- |
| 선형 변환과 행렬 (Ch.03) | 행렬은 공간을 변환하는 함수 |
| 행렬식 (Ch.06) | 변환이 공간을 얼마나 늘리거나 찌그러뜨리는지 |
| 연립방정식 (Ch.07) | $(A - \lambda I)\vec{v} = \vec{0}$ 풀기 |
| 기저 변환 (Ch.13) | 좌표계를 바꿔서 행렬을 단순화 |

## 2. 시각적 정의 — 변환 속에서 살아남는 직선

### 고유벡터 (Eigenvector)

선형 변환 $A$를 가했을 때, **방향이 바뀌지 않고 자신의 스팬(Span) 위에 그대로 남는 벡터**다.

- 변환 후 벡터는 늘어나거나, 줄어들거나, 반대로 뒤집힐 수는 있다.
- 하지만 방향 자체(그 벡터가 놓인 직선)는 변하지 않는다.

예를 들어 전단 변환(Shear)에서 $x$축 위의 벡터들을 생각해보자. 전단은 $x$축 방향 벡터는 건드리지 않고, 나머지 벡터들만 민다. 따라서 **$x$축 위의 벡터들이 이 변환의 고유벡터**가 된다.

### 고유값 (Eigenvalue, $\lambda$)

고유벡터가 변환에 의해 **늘어나거나 줄어드는 배수(Factor)**를 고유값이라 한다.

$$A\vec{v} = \lambda\vec{v}$$

| 상황 | 고유값 $\lambda$ |
| --- | --- |
| 변환 후 길이가 3배 | $\lambda = 3$ |
| 변환 후 길이가 반으로 | $\lambda = 0.5$ |
| 변환 후 반대 방향으로 뒤집힘 | $\lambda = -1$ |
| 변환 후 길이 불변 | $\lambda = 1$ |

### 3차원 회전의 예

3차원 공간을 어떤 축을 기준으로 회전시킬 때, **회전축 위의 벡터들은 방향이 전혀 바뀌지 않는다.** 따라서 회전축은 고유값 $\lambda = 1$인 고유벡터가 된다.

이를 역이용하면, **3D 회전 변환의 고유벡터를 찾으면 회전축을 알 수 있다.**

## 3. 수학적 공식과 계산 원리

### 기본 방정식

$$A\vec{v} = \lambda\vec{v}$$

- $A$: 변환 행렬
- $\vec{v}$: 고유벡터 (영벡터 아님)
- $\lambda$: 고유값

### 방정식 변형

계산하기 쉬운 형태로 한쪽으로 몰면:

$$A\vec{v} - \lambda\vec{v} = \vec{0}$$

$$(A - \lambda I)\vec{v} = \vec{0}$$

$I$는 단위 행렬(Identity Matrix). $\lambda I$는 $\lambda$를 대각성분으로 갖는 행렬.

### 핵심 조건 — 행렬식 = 0

위 방정식에서 **영벡터가 아닌** $\vec{v}$가 존재하려면, $(A - \lambda I)$가 공간을 낮은 차원으로 압축해야 한다.

공간을 낮은 차원으로 압축한다 = **행렬식이 0** (Ch.06에서 배운 내용!)

$$\det(A - \lambda I) = 0$$

이것이 **특성방정식(Characteristic Equation)**이다.

### 계산 과정 요약

1. **특성방정식** $\det(A - \lambda I) = 0$ 을 풀어 고유값 $\lambda$를 구한다.
2. 각 $\lambda$를 $(A - \lambda I)\vec{v} = \vec{0}$에 대입하여 고유벡터 $\vec{v}$를 구한다.

#### 예시: 2×2 행렬

$$A = \begin{pmatrix} 3 & 1 \ 0 & 2 \end{pmatrix}$$

특성방정식:

$$\det \begin{pmatrix} 3 - \lambda & 1 \ 0 & 2 - \lambda \end{pmatrix} = (3 - \lambda)(2 - \lambda) = 0$$

→ $\lambda_1 = 3$, $\lambda_2 = 2$

각 고유값에 대해 $(A - \lambda I)\vec{v} = \vec{0}$을 풀면 고유벡터를 구할 수 있다.

## 4. 특수한 경우들

### 고유벡터가 존재하지 않는 경우

**90도 회전 변환**을 생각해보자. 모든 벡터가 방향이 바뀌므로, 실수 범위 내에서 고유벡터가 없다. 특성방정식을 풀면 허수 $\pm i$가 나온다.

→ 기하학적으로, "회전"은 어떤 직선도 자기 자리에 놓아두지 않기 때문.

### 모든 벡터가 고유벡터인 경우

**균등 스케일링(Uniform Scaling)** — 모든 벡터를 똑같이 $k$배로 늘리는 변환.

- 모든 벡터의 방향이 그대로이므로, 모든 벡터가 고유벡터
- 고유값은 $\lambda = k$

### 전단 변환(Shear)의 경우

$x$축 방향은 그대로이고 다른 벡터들이 옆으로 밀리는 변환.

- $x$축 위의 벡터들만 고유벡터 (고유값 $\lambda = 1$)
- 고유벡터가 딱 하나의 방향뿐 → **고유기저를 이룰 수 없음**

---

## 5. 고유기저와 대각 행렬 — 변환을 가장 단순하게 보는 방법

### 고유기저 (Eigenbasis)

만약 어떤 변환 $A$의 고유벡터들이 **공간 전체를 채울 만큼(기저를 이룰 만큼)** 충분히 많다면, 그 고유벡터들을 새로운 좌표계의 기저로 삼을 수 있다.

이렇게 고유벡터들로 이루어진 기저를 **고유기저(Eigenbasis)**라 한다.

### 대각 행렬 (Diagonal Matrix)

고유기저 좌표계에서 변환을 표현하면 놀라운 일이 생긴다:

$$D = \begin{pmatrix} \lambda_1 & 0 & \cdots \ 0 & \lambda_2 & \cdots \ \vdots & & \ddots \end{pmatrix}$$

대각선 성분은 각 고유벡터 방향의 고유값이고, 나머지는 모두 0인 **대각 행렬(Diagonal Matrix)**이 된다.

기저 변환(Ch.13)의 언어로 표현하면:

$$D = P^{-1} A P$$

$P$는 고유벡터들을 열로 갖는 행렬, $D$는 대각 행렬.

### 왜 대각 행렬이 강력한가?

**행렬의 거듭제곱** 계산이 극도로 쉬워진다.

$$A^{100} = P D^{100} P^{-1}$$

$$D^{100} = \begin{pmatrix} \lambda_1^{100} & 0 & \cdots \ 0 & \lambda_2^{100} & \cdots \end{pmatrix}$$

대각 행렬의 거듭제곱은 **각 대각 성분을 거듭제곱**하면 끝! 이는 시스템의 장기적 변화(인구 모델, 마르코프 체인, 양자역학 등)를 분석할 때 핵심 도구가 된다.

---

## 6. 왜 이것이 아름다운가

고유벡터/고유값은 **변환의 고유한 언어로 변환 자체를 기술하는 방법**이다.

- 특정 좌표계(표준 기저)를 쓰면 행렬이 복잡해 보인다.
- 하지만 변환이 자연스럽게 선호하는 좌표계(고유기저)를 쓰면, 변환은 그저 "각 축 방향으로 얼마나 늘리느냐"라는 단순한 정보만 남는다.

이것이 고유벡터/고유값 분해(Eigendecomposition)의 핵심 철학이다.

## 핵심 정리 한눈에

```
고유벡터            →  선형 변환 후에도 방향이 바뀌지 않는 특별한 벡터
고유값 λ            →  고유벡터가 얼마나 늘어나/줄어드는지를 나타내는 배수
기본 방정식          →  Av = λv  ↔  (A − λI)v = 0
특성방정식           →  det(A − λI) = 0  →  이를 풀어 고유값을 구한다
고유기저            →  고유벡터들로 이루어진 기저 (공간 전체를 채울 때 가능)
대각 행렬           →  고유기저 좌표계에서의 변환 표현 → D = P⁻¹AP
거듭제곱 활용        →  Aⁿ = PDⁿP⁻¹,  Dⁿ의 대각 성분 = λᵢⁿ
고유벡터 없는 경우    →  90도 회전처럼 모든 벡터 방향이 바뀌면 실수 고유벡터 없음
```
