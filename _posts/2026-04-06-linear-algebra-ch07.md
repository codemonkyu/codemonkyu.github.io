## 1. 선형대수학의 핵심 응용 — 방정식 시스템 해결

선형대수학이 강력한 이유는 **선형 방정식 시스템을 기하학적으로 이해**하고 풀 수 있기 때문이다.

선형 방정식 시스템의 특징:

- 각 변수는 상수에 의해 스케일링
- 스케일된 변수들이 서로 더해지는 형태
- 지수나 복잡한 함수 없음

이를 행렬-벡터 곱으로 표현:

```
Ax = v
```

| 기호 | 의미 |
| --- | --- |
| `A` | 계수 행렬 (상수들) |
| `x` | 변수 벡터 (구해야 할 것) |
| `v` | 결과 벡터 |

기하학적 해석: **선형 변환 A를 적용했을 때 v에 도달하는 벡터 x를 찾아라**

---

## 2. 역행렬 (Inverse Matrix)

### 역행렬이 존재하는 경우: det(A) ≠ 0

공간이 저차원으로 찌그러지지 않는 경우 → **유일한 해가 항상 존재**

역행렬 A⁻¹의 핵심 성질:

```
A⁻¹A = I  (단위 행렬 — 아무것도 안 하는 변환)
```

방정식 풀이:

```
Ax = v
A⁻¹(Ax) = A⁻¹v
x = A⁻¹v
```

기하학적으로 → v가 어디서 왔는지 변환을 거꾸로 추적

### 역행렬이 없는 경우: det(A) = 0

공간이 더 낮은 차원으로 찌그러질 때:

- 3D → 2D 평면 (det = 0)
- 2D → 1D 선 (det = 0)

선을 평면으로 되돌릴 수 없듯이 **역행렬 불가능**

> ⚠️ 단, 역행렬이 없어도 해가 존재할 수 있다.  
> 조건: v가 열 공간(Column Space) 안에 있을 때

---

## 3. 랭크 (Rank)

**랭크 = 변환 결과(출력)의 차원 수**

| 출력 공간 | 랭크 |
| --- | --- |
| 1차원 직선 | 1 |
| 2차원 평면 | 2 |
| 3차원 전체 | 3 (Full Rank) |

- 랭크가 열의 개수와 같으면 → **Full Rank 행렬**
- `det = 0` 이라는 것보다 더 구체적인 정보 제공

---

## 4. 열 공간 (Column Space)

**열 공간 = 행렬 A의 모든 가능한 출력 벡터들의 집합**

- 행렬의 각 열 = 변환된 기저 벡터
- 이 열 벡터들이 생성(span)하는 공간
- 랭크 = 열 공간의 차원
- 영 벡터(0)는 **항상** 열 공간에 포함

`Ax = v` 에서 해가 존재하려면 → **v ∈ 열 공간** 이어야 한다

---

## 5. 영 공간 (Null Space / Kernel)

**영 공간 = 변환 후 원점(0)으로 매핑되는 모든 벡터들의 집합**

```
Ax = 0  →  해 집합 전체 = Null Space
```

| 경우 | 영 공간 |
| --- | --- |
| Full Rank | {0} 뿐 (영 벡터만) |
| 랭크 부족 | 선 또는 평면 전체가 원점으로 압축 |

v = 0 인 경우, Ax = 0 의 해 집합 = 영 공간  
기하학적으로: 평면이 선으로 압축될 때 그 평면 전체가 영 공간

---

## 6. 세 개념의 관계

```
Ax = v 를 풀 때

det(A) ≠ 0
└─ 역행렬 존재 → x = A⁻¹v (유일한 해)

det(A) = 0
├─ v ∈ 열 공간 → 해가 존재 (무수히 많음)
│   └─ 해 집합 = "특정 해 + 영 공간"
└─ v ∉ 열 공간 → 해가 없음
```

---

## 핵심 정리 한눈에

```
역행렬  (A⁻¹)  →  변환을 되돌리는 연산. det ≠ 0 일 때만 존재
랭크   (Rank)  →  변환 결과의 차원 수. Full Rank = 열 개수와 동일
열 공간 (Column Space)  →  A가 도달할 수 있는 모든 벡터의 집합
영 공간 (Null Space)    →  변환 후 0으로 매핑되는 벡터들의 집합

해의 존재:  v ∈ 열 공간 이어야 함
해의 개수:  det ≠ 0 → 유일 / det = 0 → 무수히 많음 or 없음
가능한 해:  "특정 해 + 영 공간"
```
