## 1. 크라메르 공식이란?

**크라메르 공식(Cramer's Rule)** 은 연립 선형 방정식의 해를 **행렬식(determinant)** 만으로 표현하는 공식이다.

연립방정식 `Ax = b` 에서, 해 벡터 `x`의 각 성분을 다음과 같이 구한다:

```isbl
       det(A_i)
x_i = ──────────
         det(A)
```

여기서 `A_i`는 행렬 `A`의 i번째 열을 벡터 `b`로 교체한 행렬이다.

### 왜 크라메르 공식이 중요한가?

수치 계산에선 가우스 소거법이 더 효율적이지만, 크라메르 공식은 **행렬식과 연립방정식이 어떻게 연결되는지**를 기하학적으로 드러낸다. 수식의 구조 자체가 선형대수학의 핵심 철학을 담고 있다.

## 2. 내적으로 좌표를 구할 수 없는 이유

처음엔 이런 아이디어가 떠오를 수 있다.

> "변환 후 벡터와 변환된 기저 벡터의 내적을 이용하면 입력 좌표를 알 수 있지 않을까?"

결론은 **일반적으로 불가능하다.**

선형 변환은 대부분 내적을 보존하지 않는다. 변환 전 `u · v = 3`이었다가 변환 후 완전히 다른 값이 될 수 있다. 직교하던 두 벡터도 변환 후 직교성을 잃는다.

**예외:** 회전 행렬처럼 **정규직교 변환(orthonormal transformation)** 은 내적을 보존한다. 이 경우 `AᵀA = I`가 성립하며, 내적으로 좌표를 직접 읽어낼 수 있다. 그러나 이건 특수한 경우다.

| 변환 종류 | 내적 보존? | 좌표를 내적으로 복원? |
| --- | --- | --- |
| 회전 (정규직교) | ✅ 보존 | ✅ 가능 |
| 전단 (shear) | ❌ 비보존 | ❌ 불가 |
| 스케일링 | ❌ 비보존 | ❌ 불가 |
| 일반 변환 | ❌ 비보존 | ❌ 불가 |

## 3. 핵심 아이디어: 좌표를 넓이/부피로 해석

크라메르 공식의 진짜 천재성은 여기서 나온다.

### 2D에서의 직관

미지수 벡터 `v = (x, y)`가 있다고 하자.

- **y 좌표** = 기저 벡터 `î`(i-hat)와 `v`가 만드는 평행사변형의 **부호 있는 넓이**
- **x 좌표** = `v`와 기저 벡터 `ĵ`(j-hat)가 만드는 평행사변형의 **부호 있는 넓이**

왜 이게 성립할까?

기저 벡터가 표준 기저(`î = (1,0)`, `ĵ = (0,1)`)일 때, `î`와 `v`로 만든 평행사변형은:

```gml
det([î | v]) = det([[1, x], [0, y]]) = 1·y - 0·x = y
```

즉 y좌표가 정확히 그 평행사변형의 넓이다! 마찬가지로:

```gml
det([v | ĵ]) = det([[x, 0], [y, 1]]) = x·1 - y·0 = x
```

이 관계는 **좌표 = 특정 평행사변형의 부호 있는 넓이**라는 강력한 기하학적 의미를 가진다.

### 3D로의 확장

3D 벡터 `v = (x, y, z)`에서:

- **z 좌표** = `î`, `ĵ`, `v`로 만들어지는 평행육면체(parallelepiped)의 부호 있는 부피

```stylus
det([î | ĵ | v]) = z
```

이 패턴이 임의의 차원으로 자연스럽게 확장된다.

## 4. 변환 후에도 비율이 유지되는 이유

이제 핵심 논증이다. 행렬 `A`로 변환을 적용하면 어떤 일이 생길까?

### 행렬식의 스케일링 속성

> 선형 변환 `A`를 적용하면, **모든 넓이/부피는 `det(A)`배로 스케일된다.**

이것은 행렬식의 가장 근본적인 의미다 (Ch.6에서 다룬 내용). 변환 전 넓이가 `S`였다면, 변환 후 넓이는 `det(A) · S`가 된다.

### 크라메르 공식의 유도

`Av = b` 를 풀고자 한다. y좌표를 구해보자.

변환 전, y좌표는 `det([î | v]) = y` (넓이 = y).

변환 후, 이 평행사변형은 어떻게 될까?

- `î`는 `A`의 첫 번째 열 `A₁`로 변환된다
- `v`는 출력 벡터 `b`로 변환된다

따라서 변환 후 평행사변형의 넓이 = `det([A₁ | b])`

행렬식의 스케일링 법칙에 의해:

```
det([A₁ | b]) = det(A) · y
```

따라서:

```
      det([A₁ | b])
y  = ───────────────
          det(A)
```

마찬가지로 x좌표:

```
      det([b | A₂])
x  = ───────────────
          det(A)
```

이것이 바로 **크라메르 공식**의 기하학적 유도다.

### 일반화 (n차원)

`Ax = b` 에서 i번째 성분:

```dns
        det(Aᵢ)
xᵢ  = ──────────    단, Aᵢ = A의 i번째 열을 b로 교체한 행렬
         det(A)
```

## 5. 수치 예시로 확인

```angelscript
A = [[2, -1],    b = [0]
     [1,  3]]        [7]

det(A) = 2·3 - (-1)·1 = 7

       det([[0, -1],        0·3 - (-1)·7     7
x  =       [7,  3]])  = ──────────────── = ─── = 1
            ──────────           7           7
               7

       det([[2, 0],         2·7 - 0·1       14
y  =       [1, 7]])   = ──────────────── = ─── = 2
            ──────────          7            7
               7
```

검증: `2(1) - (-1)(2) = 4 ≠ 0` → `2·1 + (-1)·2 = 0` ✅, `1·1 + 3·2 = 7` ✅

## 6. 크라메르 공식의 한계와 의의

| 항목 | 내용 |
| --- | --- |
| **계산 복잡도** | O(n!) — 가우스 소거법 O(n³)보다 훨씬 느림 |
| **적용 조건** | `det(A) ≠ 0` (역행렬 존재 시에만) |
| **실용성** | 소규모(2×2, 3×3)에서만 실용적 |
| **의의** | 해의 구조와 행렬식의 관계를 명확히 드러냄 |

크라메르 공식은 "계산 도구"로서보다 **선형대수학의 구조를 이해하는 창(窓)** 으로서 더 가치있다.

## 핵심 정리 한눈에

```
크라메르 공식의 기하학적 의미:

좌표 (x, y) = 특정 평행사변형의 부호 있는 넓이
  → y = det([î | v]) / 1 = 평행사변형 넓이
  → 변환 후: 넓이가 det(A)배로 스케일됨

크라메르 공식 xᵢ = det(Aᵢ) / det(A)
  Aᵢ = i번째 열을 출력벡터 b로 교체한 행렬

핵심 연결고리:
  좌표 → 넓이/부피  
  변환 → det(A)배 스케일
  ∴ 변환 후 넓이 / det(A) = 원래 좌표

내적이 실패하는 이유:
  일반 변환은 내적 비보존
  정규직교 변환만 내적 보존 (AᵀA = I)
```
