## 1. 차원 간 변환도 선형 변환이다

지금까지의 논의는 주로 **같은 차원 내의 변환** (2D → 2D, 3D → 3D)이었지만,
**다른 차원 간의 변환**도 완벽하게 합리적인 선형 변환이다.

선형 변환의 특징은 차원이 달라도 동일하게 유지된다:

- 격자선이 평행하고 등간격 유지
- 원점은 원점으로 매핑

**시각화 포인트**: 입력 공간과 출력 공간이 다르기 때문에,
같은 공간에서 변환되는 것처럼 보이지 않고 **두 공간을 분리해서 시각화**하는 것이 유용하다.

## 2. 비정방 행렬의 구조

행렬의 크기가 변환의 방향을 결정한다:

| 행렬 크기 | 열 | 행 | 변환 방향 |
| --- | --- | --- | --- |
| 3×2 행렬 | 2 (입력 차원) | 3 (출력 차원) | 2D → 3D |
| 2×3 행렬 | 3 (입력 차원) | 2 (출력 차원) | 3D → 2D |
| 1×2 행렬 | 2 (입력 차원) | 1 (출력 차원) | 2D → 1D |

```
열의 수 = 입력 공간의 기저 벡터 수 = 입력 차원
행의 수 = 각 기저 벡터 착지 좌표 수 = 출력 차원
```

---

## 3. 각 케이스별 이해

### 3×2 행렬: 2D → 3D

i-hat → (2, -1, -2), j-hat → (0, 1, 1) 이면:

```
A = [ 2   0 ]
    [-1   1 ]
    [-2   1 ]
```

- 두 기저 벡터가 3D 공간 안에 착지
- 열 공간 = 3D 공간의 원점을 지나는 **2D 평면**
- Full Rank (열 공간의 차원 = 입력 차원 = 2)

### 2×3 행렬: 3D → 2D

- 세 기저 벡터가 2D 평면 안에 착지
- 3D 공간이 2D 평면으로 압축됨

### 1×2 행렬: 2D → 1D

```
A = [ a   b ]
```

- 2D 벡터를 받아 **스칼라 값** 하나를 출력
- 선형성: 등간격 점들의 선이 수직선에 매핑된 후도 등간격 유지
- **내적과 밀접한 관련** (다음 챕터에서 다룰 예정)

---

## 4. 랭크의 재해석

비정방 행렬에서 **Full Rank**의 의미:

> 열 공간의 차원 수 = 입력 공간의 차원 수

- 3×2 행렬의 Full Rank = Rank 2 (2D 평면으로 착지)
- 출력 공간 전체를 채우지 않아도 Full Rank 가능

---

## 5. 행렬 곱셈과 연립방정식의 확장

비정방 행렬 맥락에서 스스로 탐구해볼 것:

| 개념 | 비정방 행렬에서의 의미 |
| --- | --- |
| 행렬 곱셈 | 차원이 다른 변환의 합성 |
| Ax = v | 입력 차원 ≠ 출력 차원인 방정식 시스템 |
| 열 공간 | 출력 공간 내 도달 가능한 부분공간 |
| 영 공간 | 원점으로 압축되는 입력 벡터들 |

## 핵심 정리 한눈에

```
행렬 크기 해석
  m×n 행렬  →  n차원에서 m차원으로의 변환
  열(column) 수  =  입력 차원
  행(row) 수     =  출력 차원

주요 케이스
  3×2  →  2D → 3D  (열 공간: 3D 속 2D 평면)
  2×3  →  3D → 2D  (차원 압축)
  1×2  →  2D → 1D  (내적과 연결)

Full Rank 조건
  열 공간의 차원 = 입력 공간의 차원
```
