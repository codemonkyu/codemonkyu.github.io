## 1. 행렬식이란 무엇인가

선형 변환은 공간을 늘리거나 찌그러뜨린다. **행렬식(determinant)** 은 이 변환이 면적(2D) 또는 부피(3D)를 얼마나 변화시키는지 나타내는 **하나의 숫자**다.

핵심 아이디어: 단위 정사각형(1×1)의 면적이 변환 후 어떻게 바뀌는지 추적하면, **공간 내 모든 영역**의 면적 변화를 알 수 있다.

> 격자선이 평행하고 균등하게 유지되므로, 모든 격자 정사각형에 동일한 비율이 적용된다.

---

## 2. 행렬식 값의 의미

| 행렬식 값 | 의미 |
| --- | --- |
| det = 6 | 면적이 **6배**로 확대 |
| det = 1 | 면적 **변화 없음** |
| det = 1/2 | 면적이 **절반**으로 축소 |
| det = 0 | **차원 축소** — 선이나 점으로 찌그러짐 |
| det < 0 | 면적 스케일링 + **공간 방향 반전** |

### 예시: 스케일링 행렬

```
[ 3  0 ]
[ 0  2 ]
```

- î → (3, 0)으로 3배 확장, ĵ → (0, 2)로 2배 확장
- 1×1 정사각형 → 3×2 직사각형
- **det = 6** (면적 6배)

### 예시: 전단 변환

```
[ 1  1 ]
[ 0  1 ]
```

- 단위 정사각형 → 평행사변형으로 기울어지지만 **면적은 1 유지**
- **det = 1**

---

## 3. 행렬식이 0인 경우: 차원 축소

행렬식이 0이라는 것은 **모든 공간이 더 낮은 차원으로 찌그러진다**는 의미다.

| 차원 | det = 0의 결과 |
| --- | --- |
| 2D | 선(line) 또는 점(point)으로 축소 |
| 3D | 평면, 선, 또는 점으로 축소 |

이는 **행렬의 열이 선형 종속(linearly dependent)** 이라는 뜻이기도 하다. 선형 방정식 시스템의 해를 판단할 때 매우 중요한 역할을 한다.

---

## 4. 음수 행렬식: 공간의 방향 반전

행렬식이 음수라는 것은 **공간의 방향(orientation)이 뒤집혔다**는 의미다.

### 2D에서의 방향 판단

- 변환 전: ĵ가 î의 **왼쪽**에 위치 → 정방향
- 변환 후: ĵ가 î의 **오른쪽**에 위치 → **방향 반전!**

2D 공간을 종이로 생각하면, 방향 반전은 **종이를 뒤집는 것**과 같다.

```
det = -3  →  공간이 뒤집히고 면적이 3배 확대
|det| = 3  →  면적 스케일링 팩터
```

### 방향 반전의 자연스러운 흐름

```
î와 ĵ가 가까워짐  →  det이 0에 접근
일직선이 됨        →  det = 0
계속 진행           →  det < 0 (방향 반전)
```

### 3D에서의 방향 판단: 오른손 법칙

- 변환 후 î, ĵ, k̂에 **오른손 법칙** 적용 가능 → det > 0
- **왼손**으로만 가능 → det < 0 (방향 반전)

---

## 5. 3차원 행렬식: 부피 스케일링

3D에서 행렬식은 **부피가 얼마나 확대되는지**를 나타낸다.

- 1×1×1 정육면체 → 변환 후 **평행육면체(parallelepiped)**
- 행렬식 = 평행육면체의 부피 (부호는 방향)

| det 값 | 3D에서의 의미 |
| --- | --- |
| det > 0 | 부피 확대, 오른손 법칙 유지 |
| det < 0 | 부피 확대 + 방향 반전 |
| det = 0 | 평면/선/점으로 찌그러짐 (열이 선형 종속) |

---

## 6. 행렬식 계산

### 2×2 행렬

```
det([ a  b ]) = ad - bc
   ([ c  d ])
```

각 항의 직관적 의미:

| 조건 | 해석 |
| --- | --- |
| b = c = 0 | `ad` = 직사각형 면적 (î가 a배, ĵ가 d배) |
| b 또는 c만 0 | 평행사변형, 밑변 a × 높이 d → 면적 `ad` |
| b, c ≠ 0 | `bc` 항 = 대각선 방향 늘어남/찌그러짐 보정 |

### 행렬 곱의 행렬식

```
det(A · B) = det(A) × det(B)
```

직관: A가 면적을 3배, B가 면적을 2배로 만들면 → A·B는 면적을 6배로 만든다.

---

## 핵심 정리 한눈에

```
행렬식          →  변환의 면적(2D)/부피(3D) 스케일링 팩터
det > 0         →  면적/부피 확대, 방향 유지
det < 0         →  면적/부피 확대 + 방향 반전
det = 0         →  차원 축소 (선형 종속)
|det|           →  실제 스케일링 크기
2×2 공식        →  ad - bc
det(AB)         →  det(A) × det(B)
핵심 교훈        →  계산보다 의미를 이해하는 것이 본질
```
