## 1. 2차원에서 3차원으로의 확장

2차원 선형 변환의 핵심 아이디어 — **기저 벡터의 이동만 추적하면 전체 변환을 알 수 있다** — 는 3차원에서도 그대로 적용된다.

차이점은 기저 벡터가 2개에서 **3개**로 늘어난다는 것뿐이다.

| 차원 | 기저 벡터 | 행렬 크기 |
| --- | --- | --- |
| 2D | î, ĵ | 2×2 |
| 3D | î, ĵ, k̂ | 3×3 |

3차원 선형 변환의 시각적 의미:

- 3차원 벡터를 입력으로 받아 다른 3차원 벡터를 출력
- **격자선이 평행하고 간격이 일정하게 유지**되면서 공간의 모든 점이 이동
- **원점은 고정**된 상태로 유지

---

## 2. 3차원 기저 벡터와 3×3 행렬

3차원 공간에서는 세 개의 표준 기저 벡터를 사용한다:

```
î = (1, 0, 0)  →  x축 방향
ĵ = (0, 1, 0)  →  y축 방향
k̂ = (0, 0, 1)  →  z축 방향
```

변환 후 각 기저 벡터가 이동한 좌표를 **행렬의 열(column)** 로 기록한다:

```
        [ ← î 이동 → ]   [ ← ĵ 이동 → ]   [ ← k̂ 이동 → ]
행렬 =  [  a  d  g ]
        [  b  e  h ]
        [  c  f  i ]
          1열      2열      3열
```

즉, **9개의 숫자**로 3차원 공간의 변환을 완전히 설명할 수 있다.

---

## 3. 예시: y축 기준 90° 회전

공간을 y축을 중심으로 90도 회전시키는 변환을 생각해 보자.

각 기저 벡터의 이동:

| 기저 벡터 | 변환 전 | 변환 후 |
| --- | --- | --- |
| î | (1, 0, 0) | (0, 0, -1) |
| ĵ | (0, 1, 0) | (0, 1, 0) |
| k̂ | (0, 0, 1) | (1, 0, 0) |

이를 행렬로 표현하면:

```
R_y(90°) = [  0  0  1 ]
           [  0  1  0 ]
           [ -1  0  0 ]
```

ĵ가 제자리에 머무는 이유는 **y축이 회전축**이기 때문이다.

## 4. 벡터 변환: 3×3 행렬 곱셈

좌표 (x, y, z)를 가진 벡터의 변환은 2차원과 동일한 원리로 동작한다.

```
v = x·î + y·ĵ + z·k̂
```

변환 후:

```
T(v) = x·T(î) + y·T(ĵ) + z·T(k̂)
```

행렬로 표현하면:

```
[ a  d  g ] [ x ]     [ ax + dy + gz ]
[ b  e  h ] [ y ]  =  [ bx + ey + hz ]
[ c  f  i ] [ z ]     [ cx + fy + iz ]
```

각 좌표가 해당 기저 벡터를 **스케일링하고 더하는 지침** 역할을 한다는 핵심 아이디어는 차원이 달라져도 변하지 않는다.

---

## 5. 3×3 행렬 곱셈과 변환의 합성

두 3×3 행렬을 곱하는 것은 **두 변환을 연속으로 적용하는 것**과 같다.

```
(A · B) · v  =  A · (B · v)
```

적용 순서: **오른쪽 행렬(B)의 변환을 먼저** → 그 다음 왼쪽 행렬(A)의 변환

실제 계산 방법도 2차원과 동일한 원리:

1. B의 각 열(기저 벡터의 이동)에 대해
2. A를 곱해서 최종 이동 위치를 구한다
3. 그 결과가 곱셈 행렬의 각 열이 된다

```
A · B = [ A·b₁ | A·b₂ | A·b₃ ]
          1열     2열     3열
```

---

## 6. 실용적 응용

3D 행렬 곱셈이 특히 중요한 분야:

| 분야 | 활용 |
| --- | --- |
| **컴퓨터 그래픽** | 3D 모델의 회전, 스케일링, 투영 |
| **로봇 공학** | 관절 회전, 좌표계 변환 |
| **물리 시뮬레이션** | 강체 운동, 유체 역학 |

핵심 이점: **복잡한 3차원 회전**을 **개별적이고 이해하기 쉬운 회전의 조합**으로 분해할 수 있다.

예를 들어, 임의 축에 대한 회전을 x, y, z축 회전의 합성으로 표현:

```
R = R_z(γ) · R_y(β) · R_x(α)
```

---

## 핵심 정리 한눈에

```
2D → 3D 확장       →  기저 벡터 2개 → 3개 (î, ĵ, k̂), 행렬 2×2 → 3×3
3×3 행렬의 열       →  각 기저 벡터가 변환 후 이동한 좌표
9개의 숫자          →  3차원 변환을 완전히 설명
벡터 변환           →  x·T(î) + y·T(ĵ) + z·T(k̂)
행렬 곱셈           →  오른쪽 변환 먼저, 왼쪽 변환 다음
변환 합성           →  복잡한 회전 = 단순 회전들의 조합
핵심 불변 원리      →  격자선 평행 + 균등 간격 + 원점 고정
```
